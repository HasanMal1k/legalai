The Pakistan Penal Code Act, 1860 — Overview
The Pakistan Penal Code Act, 1860 (Act, 1870, Federal).
This Act amends the Indian Penal Code by substituting and inserting new sections regarding conspiracy, disaffection, escape from custody, lotteries, and causing death by negligence. It also repeals several earlier statutes related to criminal justice administration and lottery suppression.
Subjects: amendment, conspiracy, disaffection, escape from custody, lotteries, causing death by negligence.
